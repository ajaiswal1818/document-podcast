# document-podcast

A lightweight project scaffold for generating a podcast from source documents.

## Layout

- `models/` for model artifacts
- `data/input/` for source documents
- `data/output/` for generated outputs
- `src/podcast/` for the application package

## Quick start

```bash
python -m podcast.cli
```

This project currently includes the package skeleton and placeholder modules for:
- document parsing
- LLM integration
- podcast planning and dialogue generation
- text-to-speech generation
